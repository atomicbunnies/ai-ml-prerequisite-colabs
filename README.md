# AI/ML Prerequisite Colab Assignment

This repository contains 16 executed Google Colab notebooks and their corresponding YouTube video explanations.

Each notebook includes saved code outputs and visualizations. The videos explain the main code blocks, outputs, and foundational concepts related to Python, NumPy, Pandas, visualization, linear algebra, probability, statistics, calculus, and machine learning.
